Inventory Management System Architecture

This page describes the architecture, tech stack, and data flow for the inventory management demo project.

System Architecture

Frontend (Vue 3 + Vite) | v API Client (axios) | v Backend (FastAPI) | v In-memory Mock Data (server/data/*.json loaded by server/mock_data.py)

The frontend runs independently on port 3000 and communicates with the backend API on port 8001. CORS is enabled for development, allowing the client to fetch JSON data from the backend.

Tech Stack

Frontend

  • Vue 3 + Composition API
  • Vite development server
  • Vue Router for page navigation
  • Axios for backend HTTP requests
  • Modular components and composables

Backend

  • Python FastAPI web framework
  • Pydantic models for validation
  • Uvicorn application server
  • CORS middleware enabled
  • In-memory data loaded from JSON files

Data & Runtime

  • Mock data stored in server/data/*.json
  • Data loaded by server/mock_data.py
  • No persistent database in this demo
  • Client API base URL: http://localhost:8001/api

Data Flow

Users interact with the UI, which updates filters and triggers API calls from the frontend to the backend.

Browser UI (Vue views) | v API client in client/src/api.js | v HTTP GET requests to backend endpoints | v FastAPI endpoints in server/main.py | v Filtered data from JSON mock files | v JSON response sent back to frontend

Filtering parameters include warehouse, category, status, and month. The same query parameters are reused across inventory, orders, dashboard summary, and reporting endpoints.

Key Entry Points

Frontend

  • client/src/main.js - app bootstrap and router
  • client/src/App.vue - global layout, filter bar, modals
  • client/src/api.js - backend API client
  • client/src/views/*.vue - page views for dashboard, inventory, orders, spending, demand, reports

Backend

  • server/main.py - FastAPI application and endpoints
  • server/mock_data.py - data loading from JSON files
  • server/data/*.json - mock inventory, orders, spending, demand, backlog data
  • server/requirements.txt - Python dependencies

Development Workflow

# Start backend cd server python3 main.py # Start frontend cd client npm install npm run dev

Frontend development occurs in the browser at http://localhost:3000, while backend API development is available at http://localhost:8001. The API docs are reachable at http://localhost:8001/docs.
